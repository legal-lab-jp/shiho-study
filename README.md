# 司法試験・予備試験 学習ログ

法律知識ゼロから司法予備試験・司法試験を学ぶ過程で、実際につまずいた疑問を整理した公開用サイトです。

主目的は個人の学習履歴を残すことです。同じ箇所で迷った受験生にも参考になる範囲で、確認済みのHTMLだけを公開します。

## 公開サイト

<https://mokemoke5312064.github.io/shiho-study/>

## 管理方針

- 教材のURLは `materials/<固定スラッグ>/` とし、分類を変更しても維持します。
- 科目、試験形式、学習目的、難易度は `data/catalog.json` の複数タグで管理します。
- 下書き、質問原文、調査メモ、制作手順はこの公開リポジトリへ置きません。
- 法令・公的資料の確認日と、学習用である旨を各教材へ記載します。
- 公開前にプライバシー、著作権、法的出典、表示・操作、URLを確認します。

## 再利用

リンクによる共有は可能です。本文、図表、デザインの転載、改変、再配布は許諾していません。
引用先の法令、裁判例、公的資料には、それぞれの提供元の条件が適用されます。

現時点で、このリポジトリ全体にオープンソースライセンスは設定していません。
